# BrandyMD GitHub Pages — FINAL consolidated site

Upload the CONTENTS of this ZIP to the root of your `BrandyMD.github.io` repository and commit to `main`.

Included in this one package:
- Existing site wording/design preserved
- 10 app cards on the homepage
- App titles link to their dedicated landing pages
- 10 dedicated app landing pages total
- 12 search-focused guide/article pages
- 1 homepage
- 23 searchable entry pages ("doors") total
- Updated sitemap.xml
- robots.txt
- Existing visual styling
- Google Analytics tag: G-9577M9WPJ9
- Custom GA4 event: `google_play_click`
- Google Play click parameters: link_url, link_text, page_path
- 404 page also tagged for Analytics

Important:
- `app-ads.txt` is NOT included in this package, so the existing file in your GitHub repo stays untouched.
- Upload the CONTENTS of the unzipped folder, not the outer folder itself.

After publishing:
1. Open your live site once.
2. Click a "View on Google Play →" link.
3. In GA4, check Reports → Realtime for `google_play_click`.
4. Mark `google_play_click` as a Key event in GA4.

## Upload manually to your existing GitHub Pages repository

1. Open the GitHub repository that publishes `brandymd.github.io`.
2. Back up anything you want to keep.
3. Upload the contents of this ZIP to the ROOT of that repository.
   `index.html`, `styles.css`, `robots.txt`, `sitemap.xml`, `assets/`, `contrast-checker/`, and `guides/`
   should sit at the top level.
4. Commit the changes.
5. In GitHub: Settings -> Pages.
6. Confirm Pages is publishing from the `main` branch / root.
7. Wait a few minutes, then visit https://brandymd.github.io/

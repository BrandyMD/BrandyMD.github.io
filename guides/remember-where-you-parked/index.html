How to Remember Where You Parked

Parking problems usually happen when the location felt obvious at arrival and completely different several hours later. Save both the map location and the visual context before you leave the car.

Use more than one clue

  • Location: save the car's map position.
  • Level: note the floor or deck in a garage.
  • Section: save the row, zone, color or letter.
  • Landmark: note the nearest entrance, elevator or store.
  • Photo: capture a pillar, sign or surrounding area.

For large outdoor lots

A saved map point is often the most useful clue. Add a landmark if the lot has multiple entrances or sections that look alike.

For multi-level garages

Do not rely on GPS alone. Record the floor and a nearby sign because map coordinates may not clearly distinguish vertical levels.

For airports, festivals and events

Take an extra few seconds to save the section before you join the crowd. These are the situations where a small note can prevent a long search later.
